# Cyclefy

## Deskripsi Project

**Cyclefy** adalah aplikasi mobile berbasis Flutter yang dirancang untuk membantu masyarakat mengelola barang bekas agar memiliki nilai guna kembali. Aplikasi ini mengusung konsep *Reuse, Reduce, Recycle* (3R) melalui berbagai fitur seperti donasi barang, barter, peminjaman, serta pencarian lokasi daur ulang.

Cyclefy bertujuan untuk mendorong kebiasaan penggunaan barang secara berkelanjutan dengan menyediakan platform yang memudahkan pengguna dalam berbagi, menukar, meminjam, dan menyalurkan barang yang masih layak digunakan.

## Daftar Fitur

### 1. Recycling Locator
- Menampilkan daftar lokasi daur ulang.
- Menampilkan informasi detail lokasi daur ulang.
- Membantu pengguna menemukan tempat untuk menyalurkan barang bekas.

### 2. Receiver Management
- Menampilkan daftar penerima barang.
- Menambahkan data penerima.
- Mengubah informasi penerima.
- Menghapus data penerima.

### 3. Notifications
- Menampilkan daftar notifikasi.
- Memberikan informasi terkait aktivitas dan pembaruan aplikasi.

### 4. Donasi dan Pengelolaan Barang
- Menampilkan daftar barang.
- Menambahkan dan mengelola data barang.
- Menampilkan informasi detail barang.
- Mendukung aktivitas donasi barang.

### 5. Barter dan Peminjaman
- Menampilkan daftar barang yang tersedia untuk barter.
- Mengajukan permintaan barter.
- Menampilkan daftar penawaran peminjaman.
- Mengelola informasi permintaan dan riwayat transaksi.

## Teknologi yang Digunakan

- **Flutter** – Framework pengembangan aplikasi mobile.
- **Dart** – Bahasa pemrograman utama.
- **Git & GitHub** – Version control dan kolaborasi pengembangan.



**Catatan:** Beberapa fitur pada versi pengembangan ini masih menggunakan dummy data atau penyimpanan lokal dan belum sepenuhnya terintegrasi dengan backend.
